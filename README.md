## Project Packs

### [Kora collection](project%20packs/Kora/)

Kora Starter covers the 2025 extract. Projects 2–4 share a separate four-year synthetic dataset for financial, people and operations analysis.

#### [Kora - 2025 only](project%20packs/Kora/Kora%20-%202025%20only/)

- [Edit the Kora 2025 Project Guide](project%20packs/Kora/Kora%20-%202025%20only/Kora%202025%20Project%20Guide.md)
- [Edit the Kora 2025 Database Setup Guide](project%20packs/Kora/Kora%20-%202025%20only/Kora%202025%20Database%20Setup%20Guide.md)
- [Download the complete ZIP](project%20packs/Kora/Kora%20-%202025%20only/Kora-2025-only.zip?raw=true)
- [Browse individual project files](project%20packs/Kora/Kora%20-%202025%20only/)

Download the ZIP, extract it and open `Kora 2025 Project Guide.md` and `Kora 2025 Database Setup Guide.md`. The pack includes seven CSV tables, SQL Server, SQLite, PostgreSQL and MySQL setup resources, data references, starter queries and a findings template. The guide contains the database schema and two project briefs.

Kora is a fictional Nigerian workplace supplier. The published extract contains 2025 orders and related consignments recorded through 31 December 2025. All data is synthetic; values are in NGN.
